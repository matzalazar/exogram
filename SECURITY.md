# Seguridad / Security

> **Proyecto archivado.** No hay una instancia en producción: el servicio en `exogram.app` fue dado de baja. No se atienden reportes de vulnerabilidades ni se publican parches. Si self-hosteás este código, la seguridad de tu instancia corre por tu cuenta.

> **Archived project.** There is no production instance — the service at `exogram.app` has been shut down. Vulnerability reports are no longer triaged and no patches will be published. If you self-host this code, securing your instance is on you.
